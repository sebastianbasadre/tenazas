## Reversar cambios

Revertir n8n:

1. Abrir el backup correspondiente en `tools/n8n_backups/`.
2. Restaurar el workflow por API con `PUT /api/v1/workflows/{id}` usando el
   JSON original como referencia.

Desactivar finetuned router:

```bash
cd /volume1/docker/openclaw
python3 tools/safe_config_edit.py set tenazas.use_finetuned_router=false
```

Restaurar `tenazas.json` manualmente:

```bash
cp /volume1/docker/openclaw/state/tenazas.json.20260521-135903 \
  /volume1/docker/openclaw/state/tenazas.json
sudo docker restart openclaw
```

Restaurar `openclaw.json` si alguna vez se rompe el gateway:

```bash
sudo docker exec openclaw cp /home/tenazas/.openclaw/openclaw.json.last-good \
  /home/tenazas/.openclaw/openclaw.json
sudo docker restart openclaw
```
