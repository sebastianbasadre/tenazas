   - Check `use_agent_coordinator(_load_config())`.
   - If disabled: call the existing `handle_non_skill(text, chat_id=chat_id)` path unchanged.
   - If enabled: lazily import `agent_coordinator`, call `agent_coordinator.route(text)`, and use `result["aggregated"]` only when `handled` is truthy and the aggregated text is non-empty.

   - callback handling
   - `aprobar` / `rechazar`
   - `estado homelab` / dashboard shortcuts
   - email-send follow-up
   - self-evolve follow-up detection
   - deterministic intercepted skills
4. Preserve router observability:
   - When the coordinator handled the query, emit `_log()` and `log_router_decision(...)` entries that clearly identify the coordinator path and strategy.
   - When the helper falls back to the LLM path, preserve the existing `llm_chat` logging behavior.
5. Preserve chat history behavior by continuing to append the assistant response after the reply is chosen.

Critical constraint: do not make the coordinator the entry point for intercepted skills in this plan. Deterministic skill traffic must keep its current path.
