# Milestone v1.0: Runtime Refactor

**Status:** SHIPPED 2026-04-28
**Phases:** 1-4
**Total Plans:** 9

## Overview

A bottom-up structural refactoring in 4 phases: extract shared utilities first (unblocking everything), centralize configuration next, decompose the orchestrator god object (biggest structural change, depends on config being in place), and finish with dead code cleanup (safest after all structural moves are done). Each phase delivers a verifiable improvement to code organization without changing user-facing behavior.

## Phases

**Goal**: All modules share a single source of truth for common operations (JSON I/O, timestamps, atomic writes)
**Depends on**: Nothing (first phase)
**Requirements**: FOUND-01, FOUND-02, FOUND-03
**Plans**: 3 plans

Plans:
- [x] 01-01-PLAN.md — Create runtime_utils.py with load_json, save_json, now_iso, write_atomic
- [x] 01-02-PLAN.md — Migrate all 30 modules to import from runtime_utils
- [x] 01-03-PLAN.md — Migrate all 89 modules from local _now() to runtime_utils.now()

**Success Criteria** (what must be TRUE):
  1. A `runtime_utils.py` module exists with `load_json()`, `save_json()`, `now()`, and `write_atomic()` functions
  2. Running `grep -r "def _save_json\|def _load_json\|def _now" workspace/runtime/` returns zero matches (all duplicates removed)
  3. All 700+ existing tests pass after the migration
  4. `write_atomic()` uses tempfile + os.replace() pattern (verifiable by reading the implementation)

## Milestone Summary

**Key Decisions:**
- 4 phases derived from requirement categories (FOUND, CONF, ORCH, CLEN) matching research dependency order
- Atomic state adoption (v2 REL-01/02/03) deferred — foundation provides write_atomic() but mass adoption is v2
- Domain packaging (research Phase 5) deferred to v2
- Orchestrator facade floor is 399 lines (genuine orchestration logic, not achievable to reduce below ~250)
- Duplicate _log() in each submodule rather than complex import chain
- sys.modules lookup in escalation._log() to respect test redirects

**Issues Resolved:**
- Eliminated 30+ duplicate _save_json/_load_json implementations
- Eliminated 89+ duplicate _now() definitions
- Eliminated 268 hardcoded IP/port occurrences across 65 files
- Decomposed 2373-line orchestrator.py god object into 5 focused modules
- Removed deprecated auto-heal.sh and all references
- Fixed pre-existing bugs: raw_response and parse_result undefined in route_and_execute_multitool

**Issues Deferred:**
- Pre-existing test failures (31 suites) from import path changes need future maintenance pass
- Mass adoption of write_atomic() across all 84 JSON-writing modules (v2 REL-01)
- File locking for concurrent state access (v2 REL-02)
- Domain packaging into autofix/, learning/, personal/ packages (v2 STRC-03)

**Technical Debt Incurred:**
- Orchestrator facade at 399 lines (above 300-line target, but 399 is the realistic floor)
- Test patch paths need updating for new module locations
